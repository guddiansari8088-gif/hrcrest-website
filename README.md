# HR Crest Management Solution — Corporate Website

A modern, responsive corporate website designed and developed for **HR Crest Management Solution** to showcase their HR consultancy, recruitment, and workforce management services.

🌐 **Live Website:** [https://hrcrest.in](https://hrcrest.in)

---

## ✨ Key Features
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
- **Interactive UI:** Smooth navigation, service sections, and quick-access footer links.
- **Direct Client Engagement:** Integrated WhatsApp and direct call widgets for instant client inquiries.
- **SEO Ready:** Configured with `sitemap.xml`, `robots.txt`, and semantic HTML structure for search engine visibility.

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript
- **Hosting & Deployment:** Netlify (with Custom `.in` Domain & SSL)
- **SEO & Analytics:** Google Search Console

## 🚀 Deployment
The project is live and hosted on Netlify with continuous SSL security enabled at **[hrcrest.in](https://hrcrest.in)**.
